[production.py](production.py)只做坐标、记录及机械裁拼，不会调用生图模型。用带Pillow的Python运行，参数模板如下；先从progress和当前索引确定位置与新版本号，避免重跑已存在输出：

1. `production.py prepare <r> <c> <sr> <sc> --attempt <n>` 生成布局引导和坐标；已有批次不用重新init。
2. `production.py overlap <stem> <邻片stem> [更多邻片stem]` 将当前已选用邻片的原尺寸重叠区放入引导；多邻片交点须另行检查。
3. `production.py request <stem> <主要邻片stem>` 保存参考元数据；另存实际prompt，用内置工具生成并保存receipt，再执行 `production.py ingest <stem> <工具返回图片路径>` 落盘、实测和记录。工具本次上限5张参考，多邻片可用已记录的原尺寸约束图承载。
4. `production.py seamcheck <左/上stem> <右/下stem> <horizontal|vertical> <QA名称>` 检查规则网格邻片。几何不符须内置重绘；不能用羽化遮掩。横向两片修补可用 `resolvepair <a> <b> <repair> <outa> <outb>`：a/b须横向相隔1024、顶边y相同，三张均为1254原生正方图；修补片顶边y须相同，其全局x相对a的偏移由记录计算，现支持0–1024（本次为700）。它不是任意位置、纵向修补或整块4K合成器。
5. 每步维护progress与选用索引，完整4K无损导出后保存贡献清单、哈希和接缝证据。跨区北边y=28672、东边x=28672由root协调复核，未经核验不得增加正式验收数量。

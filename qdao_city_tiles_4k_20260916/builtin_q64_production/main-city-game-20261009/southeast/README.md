- candidate/latest-assembly.json 与 progress.json 指向当前候选、上下文和装配/修补配方。
- native/、records/ 和 repairs/ 保存请求、提示词、真实回执、来源哈希和局部修补坐标。工具未披露的实际型号/质量保持 null。

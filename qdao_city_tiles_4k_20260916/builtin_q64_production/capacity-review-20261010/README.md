## 规划假设与区间

以下不是行业承诺或容量测试，只用于启动真实角色占位试验。每人 25～36 世界平方单位对应平均方格间距 5～6；仍可能存在服饰、姓名遮挡，并不保证所有角色轮廓互不重叠。保留 25% 可走面积余量给通行、组队和局部聚集：

`每图可走面积目标 = 5000 × 每人面积 × 1.25 = 156,250～225,000`

这是旧图已验证可走面积的约 **6.30～9.07 倍**。25% 余量只是规划参数，不能把玩家聚集热点视为自动解决。

村/岛人数与主城一样，但其世界总面积只有主城 3/4，所以更小的地图是重要约束。设村/岛可走率为 `q`，其边长 `S = sqrt(目标可走面积 / q)`，主城边长 `M = S / sqrt(0.75)`。如主城可走率更低，还需单独满足主城自身面积约束。

| 村/岛实际可走率假设 | 25/人+25%余量：村岛边长 / 主城边长 | 36/人+25%余量：村岛边长 / 主城边长 |
|---|---:|---:|
| 35% | 668 / 772 | 802 / 926 |
| 45% | 589 / 680 | 707 / 816 |
| 60% | 510 / 589 | 612 / 707 |
| 70% | 472 / 546 | 567 / 655 |

这里海水、屋顶、不可走坡地、墙、树和障碍不算可走面积。原规划文档直接使用 60%～70% 不能视为新岛屿已测得的比例；旧地图实际仅 27.57%。当前三图没有可复核遮罩，故不能从“大片灰色地板”目测宣布上述比例通过。

## 可落地的试验建议

优先保持当前人物世界尺度、已确认建筑和短南北出入口，从新版布局生成可走遮罩，再做占位试验。建议用 **主城约 700×700、村/岛各约 606.22×606.22** 作为一组中间尺度试验，面积比严格 0.75。小图每张至少要有 156,250 可走单位²，即全图可走率至少 **42.52%**；若测得 45%，小图可走面积为 165,375，主城为 220,500。该方案只覆盖 25/人+余量目标，不能同时声称已达到 36/人+余量。

如果希望先按 36/人+余量试验且小图可走率确实至少 60%，可试 **主城 720×720、村/岛各 623.54×623.54**；小图可走面积 233,280。若图中海水/建筑占用使可走率低于约 58%，这个尺寸仍不能达到目标。

以上是供比较的实验参数，**不是用户已批准的扩图规格，也不应立即据此增加数千生图任务**。应先得到带真实角色、名字、宠物及热点的可查看占位结果；然后固定世界比例、确认资源密度、再决定是否补绘真正增加的道路与活动空间。不能整体拉伸城镇并同时宣称建筑比例、清晰度和容量都不变。

## 64K 与清晰度必须分开说明

| 映射方式 | 图片像素/世界单位 | 含义 |
|---|---:|---|
| 旧 6144 映射 300 | 20.48 | 目前旧地面基线 |
| 计划 65536 映射 300 | 218.45 | 原高清接入设计的像素密度 |
| 65536 映射 600 | 109.23 | 相比旧地面仍为 5.33 倍密度，但只有 64K/300 计划密度的一半 |
| 65536 映射 700 | 93.62 | 相比旧地面为 4.57 倍，只有 64K/300 计划密度的 42.86% |

因此保留当前 64K 画布扩大世界范围，未必比旧实装地图模糊，但不能说它与原 64K/300 的最近景密度完全不变，而且建筑/道路也会随映射变大。若要求**保持 218.45 像素/世界单位**，主城 700 边长需要至少 152,918 像素，按完整 4K 块上取整约 **38×38**；村/岛 606.22 各约 **33×33**，合计 3622 块。当前三图合计为 648 块，两者是完全不同的制作规模，不得悄悄替换合同。

必须先确定用户所谓“清晰度不变”的具体基线，并以真实角色近景验证，而不是机械把图片数增加。当前合同 worldSize 尚空，不能说它已经承诺 218.45 或 93.62 密度。本次不建议为了回答是否容纳 5000 就立即扩网格。

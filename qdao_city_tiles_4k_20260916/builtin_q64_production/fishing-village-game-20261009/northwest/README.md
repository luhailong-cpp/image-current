- 4096候选以原尺寸选择原生1254来源像素组成。允许整物体修复图的局部硬mask；没有放大总览、插值、涂色或羽化混合最终像素。
- 图块原点为[(列号-1)×4096,(行号-1)×4096]，半开坐标框，总画布57344×57344。总览仅提供位置参考。
- candidate4kCount为完整覆盖候选；internalPassed4kCount为内部检查通过；formalAcceptedCount还要求所需外部接缝通过，分别记录。
- 仅用内置imagegen。实际型号与质量元数据未返回，保持null；不把配置目标冒称实际结果。

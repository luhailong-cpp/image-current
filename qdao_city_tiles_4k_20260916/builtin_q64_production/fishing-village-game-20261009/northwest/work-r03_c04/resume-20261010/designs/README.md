## 必须保持的观感

整体是**清雅、明亮干净、圆润饱满的道家 Q 版高清手绘**：深玉绿／青绿标题牌与主按钮，象牙米白的温润纸面，柔和暖金细边与云纹角饰；人物圆脸大眼、短身短肢，物件有细腻手绘体积。太极、葫芦、玉珠、短流苏及少量节庆挂饰统一在同一套画法中。

界面内容区安静、清晰、留白充足，边框精致但轻巧；需要环境时沿用青绿仙山、玉瓦道观、桃花与柔和景深。验收比较画法、材质、轮廓、装饰密度、光照和信息层级，不能仅凭绿金配色判定同风格。完整制作规则与可复用提示词统一维护在 [UI 制作规范第 2 节](../qdao_ui_redesign_v5/UI_SPEC.md#2-统一视觉与控件层级)。

## 每次作图的执行方式

1. 打开并查看本次选用的成图，将其实际作为图像输入传给生图工具；提示词明确“主要风格参考”，不能只写文件路径。旧 [最初指定风格图](../docs/references/ui-style-20260910.png)可作补充，本页列出的成图是当前直接执行样板。
2. 按本次功能组织布局，保持样板画法；其他游戏截图只提取功能。角色身份、已确认功能修订和素材交付规格继续按对应专项规范执行。
3. 读取 [统一图像设置](../config/image-generation.json)与[执行策略](../docs/IMAGE_MODEL_POLICY.md)，每个新任务核对最新正式 GPT Image 与最高质量；出现更新型号或更高质量档位且入口支持时，用于后续新图。模型升级不改变已确认风格，同一批次保持设置一致。
4. 优先使用内置 `image_gen`。有模型／质量参数时显式传配置值；没有时使用宿主管理入口，以最高视觉完成度制作，并按工具返回证据记录实际结果。API／CLI 仍仅在用户明确选择后使用。
5. 出图后与本次参考成图并排检查风格和可读性；不符合时继续修正。**每张图都保存 GPT Image 版本与质量记录**，包含当次配置目标、实际提交参数、实际返回值和证据；未披露的参数标记为未确认。提示词、参考图用途、生成来源与导出信息按[逐图生成记录](../docs/IMAGE_MODEL_POLICY.md#逐图生成记录)保存，并在交付 README 提供索引。旧图记录保持原样。

UI、新图标和配套插画直接沿用这些样板；独立人物与场景保持同一美术语言，并结合[人物与场景定调](../docs/QDAO_ART_DIRECTION.md)。主城尺寸与切块执行[主城地图切图规范](../主城地图切图规范.md)。

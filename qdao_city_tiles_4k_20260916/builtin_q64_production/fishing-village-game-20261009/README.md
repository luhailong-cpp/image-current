# 渔村游戏图并行制作

用户于2026-10-09明确要求像主城一样开多个可见窗口，开始制作渔村和岛的游戏图。本地图4个窗口各负责一个象限，每区7×7块；按production-contract.json的坐标制作，禁止复用旧稿冒充新布局。

正式单块4096×4096；制作画布57344×57344，14×14共196块。这是root为整数4K分块选定的像素规格，并非用户指定世界尺寸。用户要求世界面积为主城的3/4；世界边长比例为sqrt(0.75)，客户端尺寸、导航及5000人容量仍未验收。不得把14/16边长或像素面积当作世界面积比例。

当前总览只锁布局；detail近景只锁材料与画法，它不是全图精确坐标的裁图。实际附图、实测原生尺寸，生成新细节并用相邻原生片的重叠区连续扩展。不得把低清总览放大当正式素材。每块建议4×4个1024核心+每边115上下文，预期1254原生；如实测不同，重新核算覆盖，不得拉伸凑数。

内置image_gen为唯一获授权生成路线，禁止单独计费API。读取共享图像配置，本轮继续已核对的同批设置；工具没有型号或质量选择器时，实际提交与返回保持null/未确认，逐图保留prompt、input hashes、native dimensions和receipt。

各窗口只写自己的zone子目录，区域状态写progress.json，记录generatedNativeCount、usableNativeCount、complete4kCount、formalAcceptedCount、currentTile和nextStep。一个重试不是一个完成块。root管理共享合同、跨区接缝和最终合成；窗口不可删共用参照、改客户端、提交或推送Git，也不可给其他聊天发送消息。

执行次序：查看参考→保存坐标清单/布局引导→立即生成首块原生片→以邻片继续扩展→机械拼接和原尺寸接缝检查→相邻4K块。继续本区任务，不以计划或一张示意图冒充完工。遇到实际中断则落盘断点和真实错误。

用户已授权原生素材的机械裁切/拼接。可复用既有拼接算法，但AI绘画/修补必须内置生图。加工记录不得把机械导出标成新的模型生成。正式通过后，按项目保留规则处理已无当前用途的图片，保留来源文字；当前唯一在制稿必须保留。

## 已补齐的页面

| 页面 | 可操作内容 |
|---|---|
| 帮会总览 | 公告查看、按职位编辑公告、每日签到、贡献与铜钱、驻地功能导航、帮规 |
| 成员 | 姓名搜索、在线筛选、等级／职位／周贡献排序、分页、成员资料、空列表 |
| 帮会捐献 | 两档捐献、确认与取消、余额检查、每日额度、资金／建设／个人贡献联动 |
| 帮会任务 | 完成／进行中／已领取状态、奖励领取、防止重复领取、道具进入演示背包 |
| 帮会活动 | 已开放／未开放／已结束状态、报名与取消确认、人数同步 |
| 帮会商店 | 数量与总价确认、贡献检查、剩余额度、兑换结果与演示背包 |

支持页签方向键、Home／End、Escape 关闭弹窗或窗口、关闭后重开、浏览器前进后退、页面地址恢复。数据保存到浏览器本地；保存不可用时明确显示“仅本次有效”。重置演示需要确认，取消不会丢失数据。

页面底部的“演示身份”用于检查公告权限，不改变真实帮会职务。帮会名、12名成员、额度、奖励、活动场次与商品均为本地样例；签到和捐献按浏览器本地日历日更新，任务和商品额度在重置演示后恢复。原静态图的38人等数值属于旧视觉样例，不是生产数据来源。

## 皮肤与布局

继续采用指定的道家 Q 版、深玉绿、象牙米白和暖金风格；标题、边饰、太极、灯笼和短红穗来自已经验收的正式 v10 素材。27张界面资源原字节复制，另保留2张参考图；来源、SHA、尺寸、Alpha及九宫格边距见 [asset-manifest.json](asset-manifest.json)。本轮没有新调用生图、没有改色或重裁正式资源。

窗口、按钮、页签和头像框按正式九宫格合同实现；圆徽章、标题牌、关闭按钮、流苏保持比例。字段使用清晰原生中文文本，手机将侧栏与内容重排，列表可自然纵向滚动。2560×1080成果是浏览器渲染导出，不宣称AI原生生成尺寸。

## 验证与复现

先在素材仓库根目录启动仅本机可访问的静态服务：

```powershell
python -m http.server 4345 --bind 127.0.0.1 --directory designs
```

使用当前电脑已有 Node、Playwright 和 Edge：

```powershell
node --test designs/guild-ui-v2/model.test.cjs
```

## 实际客户端

本目录是浏览器交互预览及资源包；实际 Unity 改动位于 `E:/work/mmorpg-client`，与本地演示分别验收。原生客户端查询／创建／加入／退出／解散／公告等操作只使用服务端已有 Guild 协议；捐献、活动、商店不能用浏览器的样例状态冒充服务器成功。具体客户端入口、已接协议和验收结果由 [client-integration.json](client-integration.json) 记录。

客户端没有契约的业务显示“暂未开放”，不会扣除玩家真实货币或显示虚假报名、兑换成功。浏览器测试不等于线上服务器验收，本次不部署或修改服务端。

原生入口：主城左侧「帮会 [G]」，按 G 打开、Escape 逐层关闭。原生六页是总览、成员、排行、捐献、活动、商店；浏览器中的帮会任务、签到和交易为本地演示。

实际客户端验收：Unity 6000.6.0f1，27项定向 EditMode 测试全部通过；20张实际窗口截图覆盖2560×1080、1920×1080；9张新增资源与素材源字节一致。重连隔离、权限、分页、确认弹窗及资源加载均有验证。

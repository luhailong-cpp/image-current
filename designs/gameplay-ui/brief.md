# 五行奇谈 · 任务、背包、活动 UI

- 遵循 `qdao_ui_redesign_v5/UI_SPEC.md` 第 2 节的 2026-09-10 统一规范。
- 图 A `reference-style.png` 为项目唯一美术基准，复制自 `docs/references/ui-style-20260910.png`。
- 图 B `reference-panel.png` 仅参考已确认属性窗口的面板尺寸、信息密度与边界，来源为无相性人物属性稿。
- 交付三张静态效果图：`01-quests.png`、`02-inventory.png`、`03-activities.png`。
- 整屏按 2560×1080 目标比例设计，实际原生尺寸另行如实记录。
- 游戏 UI 为主体：任务聚焦列表与任务详情，背包聚焦物品格与物品详情，活动聚焦活动分类与参与入口。
- 深玉绿标题牌、主按钮与选中态；象牙米白纸面承载内容，暖金细边与轻巧云纹区分层级。
- 保留精致高清手绘、圆润转角与道家 Q 版气质，少量太极、葫芦、玉珠或短流苏。
- 春节、元宵、中秋按页面择少量结绳、小灯笼、花灯、月轮或桂花点缀，不遮挡文字与操作区域。
- 纸面与金边保留纹理、中间调和明暗层次；清透不过曝、不泛白，避免厚重金属框与大块亮绿。
- 不额外加入抢占功能区域的大场景或全身人物；其他游戏截图仅供功能与布局参考。
- `index.html` 仅切换静态图与下载当前原图，面板内部不执行操作，未接入客户端。
